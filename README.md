## `BUILD ORDER`

1. Generate/upload the dark + light banner SVGs.
2. Fork `anuraghazra/github-readme-stats`, deploy it to Vercel, and set `PAT_1` in the Vercel environment. fileciteturn0file0L46-L55
3. Enable **Settings → Actions → General → Workflow permissions → Read and write** for this repository, then run the snake workflow once. fileciteturn0file0L88-L106
4. Add the final social links using the badge template.

### One important repository detail

GitHub only renders a profile README automatically from a **public repository whose name exactly matches the GitHub username**. This repository is currently named `GIthub_PRofile`, so it is a profile-build workspace until the content is moved into the username-matching repository. fileciteturn0file0L7-L13
